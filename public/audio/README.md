# Custom Romantic Music

Place your favorite romantic song here as:
- `music.mp3`

### Audio Features:
- If `music.mp3` is present, it will loop smoothly in the background when music is toggled on.
- If no MP3 file is placed here, the application automatically falls back to an ambient, soothing pentatonic music box synthesizer generated via the Web Audio API.
- Audio never autoplays before user interaction, conforming to modern browser policies.
