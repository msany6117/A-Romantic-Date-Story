# Custom Memory Photos

Place your own photos in this folder:
- `hero.jpg`
- `memory-01.jpg`
- `memory-02.jpg`
- `memory-03.jpg`
- `memory-04.jpg`
- `memory-05.jpg`

You can also use any image URL or file path by editing `src/config/siteConfig.ts`!
The app automatically handles missing photos with elegant photographic fallbacks.
